Cyclic Behavior Type (CBT) Tool

Test metrics and CBT estimation for cyclic direct simple shear tests on fine-grained soils

Tool About: Input format Method Symbols Citation

Input format

A CSV template is available to download and fill in with the test data that you want to analyze. Use one CSV file per cyclic direct simple shear (CDSS) test or test stage. The first row is a header.

#QuantityUnitNotes
1Times, min or hNon-decreasing
2Shear stress, τkPa, MPa, psf, psi or atmSigned (positive and negative half-cycles)
3Vertical effective stress, σ′vsame unit as τFirst row = σ′v0 at the start of cyclic loading
4Shear strain, γ% or decimalSigned
5Vertical strainanyOptional; not used in calculations
  • The record should start at the beginning of cyclic loading (after consolidation). Excess pore pressure ratio is computed as ru = (σ′v0 − σ′v) / σ′v0, as in constant-volume CDSS tests.
  • Units are set in the tool (box 1) for each file: the selection applies to files uploaded next, and changing it updates the selected file. Stress and time units only change the plot labels, because every metric uses stress or time ratios (ru, τ/σ′v0, Ratiohull, N/Ns). Shear strain entered as a decimal (e.g. 0.03) is converted to percent before any calculation, because the strain thresholds (γDA = 6% and 9%, γs = 3%) are defined in percent; results are always shown in percent.
  • The example files illustrate the unit options: Example 1 is given in minutes, psf and decimal strain, and Examples 2 and 3 in seconds, kPa and percent strain. Loading an example in the tool selects its units automatically.
  • Lines beginning with # are ignored.
  • Rows with missing values in columns 1–4 are skipped.
  • NGL database CDSS exports (DSSS_TIME, DSSS_TAU, DSSS_SIGV, DSSS_YHV, DSSS_EPSV) already use this layout.
  • Tests can also be loaded directly from the NGL database: choose Load from NGL database in box 2, sign in with your NGL account (the token is valid for 2 hours), filter the list of direct simple shear test stages, and load the selected stages. They are added to the file list with units s, kPa and % strain.
  • The models were calibrated on stress-controlled CDSS tests on intact fine-grained specimens (FC > 30%) with no initial static shear stress, carried to γDA ≥ 9%. Tests that do not reach γDA = 6% are not assessed. Use outside these conditions requires judgment.

Method

Processing and cycle detection

Stress, strain and vertical stress histories are interpolated in time with a monotonic Hermite cubic spline (SciPy PchipInterpolator), about 1,000 points per cycle. A cycle starts where shear stress crosses zero from negative to positive. Metrics are computed for every cycle.

Metrics used by the CBT models

  • ru,max: maximum excess pore pressure ratio within the cycle.
  • Ratiohull = Aloop / Ahull: area under the stress–strain loop divided by the area of its convex hull. It decreases with pinching (sand-like response).
  • RatioΔγ = Δγcyc / γFC: increase in maximum single-amplitude strain relative to the previous cycle, divided by the first-cycle maximum strain.
  • κγ: three-point curvature of γ/γs versus N/Ns (γs = 3% single amplitude), using points at 10%, 50% and 90% of the record. Positive values indicate accelerating strain accumulation.

Cycle for assessment

The tool shows CBT at the last loading cycle by default; any other cycle can be selected. Ultimate hysteretic behavior tends to stabilize by the cycle in which the double-amplitude shear strain reaches 9%, so that cycle is marked for reference and tests that stop between 6% and 9% are flagged, because the estimate may understate sand-like behavior. If a test never reaches γDA = 6%, CBT for fine-grained soils cannot be assessed and no CBT is reported because strain accumulation curvature cannot be calculated.

Analyst models

Ten analysts assigned CBT to 195 CDSS tests from the Next Generation Liquefaction database. For each analyst, the logit of CBT was regressed on a subset of the metrics with Bayesian inference (PyMC, 4 chains × 1,000 samples):

μT = log[ CBT / (1 − CBT) ] = θ · X + σ̂ ε,   ε ~ N(0, 1)

For a new test, every posterior sample s of analyst i gives μs = θs · [1, X]. The analyst's predictive distribution in logit space has mean μi = mean(μs) and variance σi2 = var(μs) + mean(σ̂s2). Using all posterior samples keeps the correlation between the intercept and the metric coefficients.

Combining analysts

Analysts are combined in logit space with equal weights wi (Brandenberg and Pretell, 2024):

μc = Σ wi μi     σc2 = Σ wi σi2 + Σ wi (μi − μc)2

The first term is within-analyst uncertainty and the second is between-analyst (epistemic) uncertainty. In the tool, the combined values μc and σc are displayed as μT and σT (see List of symbols). The tool reports the median, the 16th–84th percentiles and the mean of this distribution. Individual models are developed for each analyst using a combination of the selected metrics. CBT and its uncertainty

Each analyst model gives a normal distribution of logit(CBT); the analysts are then combined into one distribution (see Method). All μ and σ values are in logit space.

SymbolMeaning
CBTCyclic behavior type, from 0 (clay-like) to 1 (sand-like)
logit(CBT)log[CBT / (1 − CBT)]; the models work in this space
μTMean of logit(CBT). For one analyst it is μi; for the combined result it is μc, the equal-weight average of the selected analysts
σTStandard deviation of logit(CBT): the total uncertainty. For one analyst σT2 = σ coef.2 + σ̂ model2; for the combined result σT2 = σ within2 + σ between2
σ coef.Uncertainty from the model coefficients (spread of the prediction over the posterior samples)
σ̂ modelModel standard deviation: scatter of the analyst's own CBT assignments around the fitted model
σ withinWithin-analyst uncertainty: the weighted average of the analysts' σT (root of Σ wi σi2), i.e. how uncertain each analyst's own estimate is
σ betweenBetween-analyst uncertainty: spread of the analysts' μT around the combined μT (root of Σ wi(μi − μc)2), i.e. how much the analysts disagree
Medianexpit(μT) = 1 / (1 + e−μT); the value shown as the main CBT result and as the line on the gauge
MeanMean of the CBT distribution; differs from the median because the logit transformation is not linear
16–84%CBT range between the 16th and 84th percentiles, expit(μT ± σT); the shaded band on the gauge
5–95%CBT range between the 5th and 95th percentiles, expit(μT ± 1.645 σT)
Weight, wiWeight of each selected analyst in the combination (equal weights, 1 / number of selected analysts)
AnalystsNumber of analyst models used out of the ten available (select them in the Analyst models box)
