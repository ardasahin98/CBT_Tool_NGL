Troubleshooting and FAQ

Common error messages and what to do about them, and answers to questions about the results.

Error messages

A test that could not be computed shows a red error chip in the file list; hover over it, or click the test, to see the message.

MessageWhat it means and how to fix it
The file is empty.The file has a header and no data rows (comment lines starting with # don't count).
Fewer than 50 valid data rows were found…Fewer than 50 rows have numbers in all of the first four columns. Check the column order (time, shear stress, vertical effective stress, shear strain), that the file uses commas between columns and points for decimals, and that it is not saved with semicolons by a European-locale spreadsheet.
Time must be non-decreasing.Time goes backwards somewhere, for example where two test stages were pasted together. Keep only the cyclic loading stage, or make time continuous.
Fewer than two loading cycles were detected.The shear stress does not cross zero from negative to positive at least twice. Check that the shear stress column is signed and in column 2.
Strain accumulation cannot be normalized at the last cycle.The single-amplitude strain at the end of the record is zero, so κγ can't be computed. Check the strain column.
Sign-in failed. Check your NGL email and password.Use the email address of your NGL account, not the username.
The browser could not reach the NGL API from this page…The page is hosted where it can't call NGL. See Connecting to the NGL API. Uploading CSV files still works.
Admin access was refused…Untick Admin access; it is only for NGL administrators.
NGL has no time-series data for this stageThe stage exists in NGL but its data has not been uploaded. It is skipped.

The tool is slow to start

The first visit downloads about 30 MB: Python, NumPy and SciPy compiled for the browser. Later visits load them from the browser's cache. If the progress bar stalls, reload the page; on a restricted network, check that the site's vendor/ files are not blocked.

Questions

Should I read CBT at the last cycle or at γDA = 9%?

The models were calibrated on tests carried to at least γDA = 9%, by which hysteretic behavior has usually developed. For a test that goes well beyond 9%, compare the two; the CBT tab shows how the estimate develops with strain. See Which cycle to use.

My test stops before γDA = 9%. Can I use the result?

The tool reports it with a caution. The soil's ultimate hysteretic behavior and susceptibility may not have developed by the end of the test, so treat the result as provisional and use judgment.

Why is the 16–84% range so wide?

Because it includes the scatter of each analyst's own judgments and the disagreement between the ten analysts. A CBT near 0.5 with a wide range means the test does not clearly look like either kind of behavior. See Combined CBT.

Do the units change the result?

Time and stress units do not: every metric uses ratios. The strain unit does: make sure decimal strain (0.03) is marked as decimal, or the tool reads it as 0.03% and the strain thresholds are never reached.

Why is Ratiohull exactly 1.00 in some cycles?

Ratiohull is limited to 1. A value of 1 usually comes from a cycle that is cut short (often the last one, when the record stops part-way through a cycle) or from a very noisy loop. Look at that cycle in the loop plot, and read CBT at a neighbouring complete cycle if needed.

Can I use strain-controlled tests, triaxial tests or sands?

The tool will compute metrics and CBT for any record in the template layout, but the models were fitted to stress-controlled CDSS tests on intact fine-grained soils without static shear. Anything else is an extrapolation.

Is my data uploaded anywhere?

No. Files are read and processed in your browser. When you sign in to NGL, your email and password go only to NGL (directly or through the site's relay, which doesn't store them) to obtain the 2-hour token.
