Downloads

The Export box downloads the per-cycle results, a summary of a batch of tests, or the test data as loaded. Every download is a .zip file with the CSV files and a disclaimer.

Choosing the tests

The dropdown in the Export box lists the loaded tests; new tests are ticked as they are loaded. All, None and Current (only the test shown) are quick selections. Results and Raw data download the ticked tests.

Results

For one test, the .zip has <test>_CBT_cycles.csv. For several tests, it has one such file per test plus CBT_summary.csv. Both include DISCLAIMER.txt, which records the tool version, the date, the analysts used and any test that did not reach γDA = 9%.

Per-cycle file: <test>_CBT_cycles.csv

Two comment lines (starting with #) give the tool version, the file, units, analysts, the γDA = 9% cycle, how Ns was found, any caution, and the data source (for NGL tests, the NGL identifiers and index properties). Then one row per cycle:

ColumnMeaning
cycleCycle number N
gamma_SA, gamma_DASingle- and double-amplitude shear strain of the cycle (%)
CSR_cycleLargest |τ|/σ′v0 in the cycle
ruru,max, the largest excess pore pressure ratio in the cycle
hullRatiohull = Aloop/Ahull
hull_methodIntegration rule used for Aloop: Simpson's rule, or the trapezoid rule where Simpson's is unreliable (see Ratiohull)
str_accΔγcyc, increase in γSA from the previous cycle (%)
dgammaRatioΔγ = Δγcyc/γFC
kappaκγ, strain accumulation curvature (same value on every row)
CBT_median, CBT_p16, CBT_p84, CBT_meanCombined CBT: median, 16th and 84th percentiles, mean
mu_T, sigma_TCombined mean and standard deviation of logit(CBT)
sigma_within, sigma_betweenWithin- and between-analyst parts of sigma_T
<analyst>_median, _mu_T, _sigma_TThe same for each selected analyst model

Summary file: CBT_summary.csv

One row per test, for comparing many tests at once:

ColumnsMeaning
file, source, statusTest name; upload or NGL; ok, a caution, or an error message
DSSS_ID … PIFor NGL tests: NGL identifiers, lab, lab program, sample, specimen, e0, w0, LL, PL and PI
time_unit, stress_unitUnits of the input file
n_cycles, sigma_v0, CSR_max, gamma_DA_maxRecord summary (σ′v0 in the file's stress unit)
reached_gamma_DA9, gamma_DA9_cycleWhether γDA = 9% was reached, and in which cycle
N_s, N_s_basisNs, and whether it is from γSA = 3% or the last cycle
last_…Cycle, γDA, metrics and combined CBT at the last cycle
g9_…Metrics and combined CBT at the first cycle with γDA ≥ 9%

Raw data

Raw data downloads the test data as loaded, one CSV file per test:

  • NGL tests follow the layout of the NGL lab test viewer (NGL_DirectSimpleShearTest_DSSS_ID_<id>.csv), with the reference, lab, lab program, citation, specimen, sample, Atterberg limits and test metadata above the time series. Use it to cite the original source of the data.
  • Uploaded files keep their own columns and units, under a short header with the file name and units.
