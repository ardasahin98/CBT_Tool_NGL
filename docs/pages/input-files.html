Preparing test files

One CSV file per CDSS test (or test stage), with four or five columns. The tool reads any time and stress unit, and shear strain in percent or as a decimal.

The template

Download the template from box 1 of the tool, or here: CBT_CDSS_Template.csv. It has one header row:

Time,Shear Stress,Vertical Effective Stress,Shear Strain,Vertical Strain

Fill in one row per recorded point, in the order of the columns below:

#QuantityUnitNotes
1Time, ts, min or hNon-decreasing
2Shear stress, τkPa, MPa, psf, psi or atmSigned: positive and negative half-cycles
3Vertical effective stress, σ′vSame unit as τThe first row is taken as σ′v0, at the start of cyclic loading
4Shear strain, γ% or decimalSigned
5Vertical strainanyOptional; not used in the calculations

A short file looks like this (the examples have thousands of rows):

Time,Shear Stress,Vertical Effective Stress,Shear Strain,Vertical Strain
0.000,0.0,31.70,0.000,0.000
0.100,0.3,31.70,0.000,-0.007
0.200,0.9,31.68,0.001,-0.007
...

Rules

  • The first line is a header and is skipped. Further rows that are not numbers (a second header row with units, for example) are skipped too.
  • Lines that begin with # are comments and are ignored.
  • Rows with a missing or non-numeric value in columns 1–4 are skipped.
  • At least 50 valid rows and two loading cycles are needed.
  • The record should start at the beginning of cyclic loading, after consolidation: the first row's vertical effective stress is σ′v0.
  • Use a point as the decimal separator (12.5), and commas between columns.

Units

Choose the units of a file in box 1 of the tool, under the Examples. The selection applies to the files you upload next, and changing it updates the file currently shown, so you can fix the units after uploading.

  • Time and stress units only change the plot labels. Every metric uses ratios of stress or time (ru, τ/σ′v0, Ratiohull, N/Ns), so the results do not depend on them.
  • Shear strain does matter: the strain thresholds (γDA = 9%, γs = 3%) are in percent. Strain entered as a decimal (0.03) is multiplied by 100 before any calculation, and results are always shown in percent.

The excess pore pressure ratio is computed from the vertical effective stress, ru = (σ′v0 − σ′v) / σ′v0, as in constant-volume CDSS tests.

NGL exports

CDSS data exported from the NGL database (columns DSSS_TIME, DSSS_TAU, DSSS_SIGV, DSSS_YHV, DSSS_EPSV, in s, kPa and %) already use this layout and can be uploaded as they are. You can also load tests from NGL directly.

Which tests the models apply to

The models were calibrated on:

  • stress-controlled cyclic direct simple shear tests,
  • on intact fine-grained specimens (fines content above 30%),
  • with no initial static shear stress,
  • carried to a double-amplitude shear strain of at least 9%.

The tool computes CBT for any test it can read, including strain-controlled tests, reconstituted specimens or tests with static shear, but the result is then an extrapolation and needs judgment. Tests that stop before γDA = 9% get a caution.
