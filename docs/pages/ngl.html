Loading tests from the NGL database

The tool can read cyclic direct simple shear tests straight from the Next Generation Liquefaction (NGL) database through its web interface (API), so you don't have to export and upload them.

Sign in

Click Load from NGL database in box 2 of the tool. A window opens; sign in with the email address and password of your NGL account. (No account? Register at nextgenerationliquefaction.org.)

  • Your email and password are sent once, only to NGL, to obtain an access token valid for 2 hours. The password is not stored.
  • The token is kept only in this browser tab (session storage) and is forgotten when the tab is closed. The time left is shown next to the button.
  • After 2 hours you are asked to sign in again. Tests already loaded stay in the tool.

Inside the NGL website (the CBT Tool under Interpretation Tools), there is no sign-in: the tool uses the account you are logged in to NGL with. The window says "Signed in through the NGL website", and a new token is fetched from NGL when the old one runs out.

Find the tests

After signing in, the window lists the direct simple shear test stages in NGL, with the same columns as the NGL lab test viewer:

ColumnFrom NGL
Lab, Lab Program, Citation IDThe laboratory, the lab program and its citation
Sample, SpecimenSample and specimen names
e0, w0Initial void ratio and water content of the specimen (DSSG_E0, DSSG_W0)
LL, PLLiquid and plastic limits of the specimen (PLAS_LL, PLAS_PL)
Stage, Loading Type, DrainageStage number; consolidation, monotonic or cyclic loading (DSSS_TY); drained or undrained (DSSS_DR)
  • Search boxes under each column heading filter the list. Click a heading to sort by it.
  • Add column adds any other NGL field to the table.
  • Cyclic stages only (on by default) hides consolidation and monotonic stages.
  • Include unreviewed data (on by default) also lists data submitted to NGL but not yet reviewed.
  • Admin access is for NGL administrators only: it also lists data never submitted for review. Other accounts get an error. Do not redistribute such data without the data owner's permission.

Load

Tick the stages you want and click Load selected into the tool. Only the time series of those stages are downloaded. Each one is converted to the template layout (s, kPa, % strain) and added to the file list just like an uploaded file, with its NGL identifiers, lab, sample, specimen and index properties shown in the test summary and included in the downloads.

Stages that are already loaded are skipped. A stage without time-series data in NGL is reported and left out.

Terms of use

Data loaded from NGL remain subject to the NGL database's terms of use. Please cite the original sources of the data (listed in the NGL Citations table, and in the raw data download) and the NGL database:

"The browser could not reach the NGL API"

On cbttoolngl.vercel.app and inside the NGL website, the tool reaches NGL through a relay on its own address, so this usually means the NGL website is down or slow: try again later. If it keeps happening, the relay may be missing from the deployment. A copy of the tool hosted somewhere else needs its own way to reach NGL; see Running and hosting. Uploading CSV files works everywhere.
